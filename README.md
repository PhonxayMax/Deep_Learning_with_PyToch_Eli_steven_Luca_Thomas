# การเรียนรู้เชิงลึกด้วย PyTorch
## Deep Learning with PyTorch - บทเรียนและแบบฝึกหัด

### 📚 เกี่ยวกับโครงการนี้

โครงการนี้เป็นชุดของ Jupyter Notebooks ที่รวบรวมบทเรียนและตัวอย่างการใช้งาน PyTorch สำหรับการเรียนรู้เชิงลึก (Deep Learning) โดยเนื้อหาจัดตามโครงสร้างของหนังสือ "Deep Learning with PyTorch" โดย Eli Stevens, Luca Antiga และ Thomas Viehmann

### 📖 เนื้อหาในแต่ละบท

#### **บทที่ 2: การตั้งค่าและการทำงานเบื้องต้น**
- `Ch2_1_making_sure_things_work.ipynb` - การตรวจสอบการติดตั้งและการทำงานของ PyTorch
- `Ch2_2_pre_trained_networks.ipynb` - การใช้งานโมเดลที่ถูกฝึกมาแล้ว (Pre-trained Networks)

#### **บทที่ 3: Tensors และแนวคิดพื้นฐาน**
- `Ch3_1_tensors.ipynb` - การทำงานกับ Tensors (อาร์เรย์หลายมิติ)
- `Ch3_2_named_tensors.ipynb` - Named Tensors และการจัดการข้อมูล
- `CH3_perceptron_CH7_7_2_3_perceptron.ipynb` - Perceptron และการประยุกต์ใช้

#### **บทที่ 4: การจัดการข้อมูลประเภทต่างๆ**
- `Ch4_1_image_dog.ipynb` - การประมวลผลภาพ (ตัวอย่างภาพสุนัข)
- `Ch4_2_volumetric_ct.ipynb` - การจัดการข้อมูล CT Scan แบบ 3 มิติ
- `Ch4_3_tabular_wine.ipynb` - การจัดการข้อมูลแบบตาราง (ตัวอย่างข้อมูลไวน์)

#### **บทที่ 5: การเพิ่มประสิทธิภาพและการหาค่าพารามิเตอร์**
- `Ch5_1_parameter_estimation.ipynb` - การประมาณค่าพารามิเตอร์
- `Ch5_2_autograd.ipynb` - ระบบการหาอนุพันธ์อัตโนมัติ (Automatic Differentiation)
- `Ch5_3_optimizers.ipynb` - อัลกอริทึมการปรับปรุงค่าพารามิเตอร์

#### **บทที่ 6: โครงข่ายประสาทเทียม**
- `Ch6_1_neural_networks.ipynb` - โครงข่ายประสาทเทียมพื้นฐาน
- `Ch6_2_activation_functions.ipynb` - ฟังก์ชันกระตุ้น (Activation Functions)
- `Ch6_3_nn_module_subclassing.ipynb` - การสร้าง Custom Neural Network Modules

#### **บทที่ 7: ชุดข้อมูลและการจำแนกประเภท**
- `Ch7_1_datasets.ipynb` - การจัดการชุดข้อมูลใน PyTorch
- `Ch7_2_birds_airplanes.ipynb` - โปรเจ็กต์จำแนกภาพนกและเครื่องบิน
- `CH7_7_4_3_approximating_surfaces_with_perceptrons.ipynb` - การประมาณผิวโค้งด้วย Perceptrons

### 🎯 วัตถุประสงค์การเรียนรู้

1. **เข้าใจแนวคิดพื้นฐาน** - การทำงานกับ Tensors และการดำเนินการทางคณิตศาสตร์
2. **การประมวลผลข้อมูล** - การจัดการข้อมูลประเภทต่างๆ (ภาพ, ตาราง, ปริมาตร)
3. **การสร้างโมเดล** - การออกแบบและสร้างโครงข่ายประสาทเทียม
4. **การฝึกโมเดล** - เทคนิคการปรับปรุงพารามิเตอร์และการเพิ่มประสิทธิภาพ
5. **การประยุกต์ใช้** - โปรเจ็กต์จริงในการจำแนกประเภทและการวิเคราะห์

### 🚀 วิธีการใช้งาน

1. **ข้อกำหนดระบบ:**
   - Python 3.7+
   - PyTorch
   - Jupyter Notebook หรือ Google Colab
   - NumPy, Matplotlib, และไลบรารีที่เกี่ยวข้อง

2. **การเรียกใช้:**
   - เปิดไฟล์ `.ipynb` ใน Jupyter Notebook
   - รันโค้ดในแต่ละ cell ตามลำดับ
   - ศึกษาผลลัพธ์และทำความเข้าใจแนวคิด

3. **แนะนำการศึกษา:**
   - เริ่มจากบทที่ 2 เพื่อตรวจสอบการติดตั้ง
   - ศึกษาตามลำดับบทเพื่อความเข้าใจที่ดีที่สุด
   - ทดลองแก้ไขโค้ดเพื่อทำความเข้าใจเชิงลึก
